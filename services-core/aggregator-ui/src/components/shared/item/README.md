# Shared Item presentation

These components provide Item titles, ownership, signals, and Timeline
disclosures for both the live view and contextual-help scenes. They present
the data and actions supplied by callers; Product Health remains a backend fact.

Help scenes use the production markup with actions omitted and catalog
information disabled. Changes to shared markup or typography can move measured
animation targets, so review the scenes' alignment at desktop and mobile widths.
See [Contextual help](../../about/README.md) for scene conventions.
